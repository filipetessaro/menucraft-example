# Menucraft Demo

Playable Windows demo of **Menucraft**, the gamepad-first CommonUI menus, settings and loading screen plugin for
Unreal Engine. It is Epic's Third Person template set up as Menucraft's Quick start describes, packaged as a Shipping
build with UE 5.8.

**Download:** [MenucraftDemo_Windows.zip](https://github.com/filipetessaro/menucraft-example/releases/latest/download/MenucraftDemo_Windows.zip)
(375 MB). No engine needed.

1. Unzip and run `MenucraftExample.exe`.
2. The main menu opens over the level. Play loads the level with the loading screen; Escape or the controller's
   Start opens the pause menu. Settings has five tabs: graphics, audio, controls, accessibility and gameplay.
